1. Download
Click Download setup skill and save the zip.
On Windows, right-click the zip and choose Extract all.

2. Open the folder
Open the folder for your chat tool.
Not sure? Use Claude in folder 1; you need an account with that tool.

3. Add the skill
Choose your chat tool below.

CLAUDE DESKTOP OR CLAUDE.AI (folder 1) Recommended
1. In Settings, open Capabilities. Enable Code execution and file creation (also called Create and edit files).
2. Open Customize, then Skills. Click +, then Create skill, then Upload a skill.
3. Upload dreamlabs-sales-setup.zip from folder 1 without extracting it. Turn the skill on. Start a new chat.
4. Controls missing? Ask your Claude account admin or use folder 4.

CLAUDE CODE (DEVELOPERS) (folder 2)
1. Copy the dreamlabs-sales-setup folder into ~/.claude/skills/.
2. Start a new chat.

CHATGPT (folder 3)
1. If you can create or edit a GPT, open its configuration.
2. Paste chatgpt-instructions.md into Instructions.
3. Under Knowledge, upload file-format.md, interview-guide.md and sequences.md. Save it and start a new chat with it.
4. Option missing? Use folder 4 instead.

ANY OTHER CHAT (PASTE) (folder 4)
1. Open SKILL-single-file.md in a plain text editor.
2. Copy all its text.
3. Paste it into a new chat.

4. Answer the questions
Tell your chat: Help me set up Dreamlabs Sales for my business.
Answer its questions in your own words.

5. Save your files
Save each finished .md file.
If you receive text, use a plain text editor to save it, not Word.

6. Import them
Admins only
In Dreamlabs Sales Settings, click Import setup files and choose all finished .md files.
Check the preview, then save.
Only an admin can upload the finished files. Not an admin? Send the files to your admin.

7. Switch sequences on
Reload the page, then review and turn on each new sequence in the sequence editor.
New sequences start off; replacements keep their current on or off setting.

Something went wrong?
A wrong file type error means hard refresh (Ctrl+F5) and try again.
Ask your admin if the import button is missing.
